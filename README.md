# DAEDAL downloads

Free tools for video editors — Premiere Pro panels, standalone apps, LUTs, film assets and sound effects.
Browse everything, with previews and install guides, at **https://daedal-website.lucian-sofronie.workers.dev/**

Everything here is free. No accounts, no email, no paywall. Donations are welcome and never required.

| Release | What's inside |
|---|---|
| `packs-v1` | LUT collections, film grain, light leaks & burns, bokeh, flares, film damage, frames, VHS, split screens, guides, sound libraries |
| `daedal-sync-v1.0.0` | DAEDAL Sync — sync cameras and recorders by sound (Mac & Windows) |
| `backup-guard-v1.0.0` | DAEDAL Backup Guard — verify your backup copies (Mac & Windows) |
| `premiere-panels-v1` | OneShot Export, Timeline Doctor, Sync Bridge, Beat Map, Delivery Kit, Smart Bins, Voice Duck |

Found a bug or have an idea? Open an issue here.
